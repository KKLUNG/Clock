# 下班倒數計時時鐘

一個放在桌面上的彩色小時鐘，顯示離下班還有多久、今天的工作進度，上午也會顯示午休倒數。每隔一段時間還會跳出一句厭世又好笑的「心情小語」。

| 時段 | 外觀 |
|---|---|
| 早上（午休結束前） | 藍 → 青漸層，下面一行是午休倒數或「午休中」 |
| 下午 | 橘 → 黃漸層 |
| 最後一小時 | 桃紅 → 紫漸層，外框發光閃爍，右上角顯示「快下班了！」 |
| 最後 10 秒 | 中間變成大大的 10、9、8…，每秒跳動一次 |
| 下班那一刻 | 全螢幕放約 8 秒煙火，滑鼠可以直接點穿煙火，不影響工作 |
| 下班後 | 彩虹漸層，顯示「下班囉！」 |
| 週六日 | 綠色漸層，顯示「今天放假」 |

適用 Windows 10／11（64 位元），**不需要安裝 Python**。

## 安裝到新電腦

1. 把整個資料夾複製到新電腦，放在一個之後不會再搬動的位置，例如 `C:\OffWorkClock`
2. 雙擊 `OffWorkClock.exe`，螢幕右上角會出現時鐘
3. 在時鐘上按右鍵 →「設定…」，設定好上下班時間，勾選「開機自動執行」，按「儲存」

完成！之後每次登入 Windows，時鐘都會自動出現。

> 如果出現「Windows 已保護您的電腦」的藍色視窗，請點「其他資訊」→「仍要執行」。這是因為程式沒有數位簽章，不是病毒。
> 如果防毒軟體把它擋下或刪除，需要把這個資料夾加入防毒軟體的例外清單。

## 從舊版更新

1. 在舊的時鐘上按右鍵 →「結束」
2. 用新的 `OffWorkClock.exe` 覆蓋舊的，其他檔案保留不動
3. 雙擊開啟新版，按右鍵 →「設定…」→ 直接按「儲存」一次

第 3 步會把舊版的開機捷徑換成新的開機設定。舊版的 `install_startup.ps1`、`uninstall_startup.ps1` 已經用不到，可以刪除。

## 操作方式

- **移動**：用左鍵拖曳時鐘，放開後位置會自動記住
- **右鍵選單**：
  - 來一句：馬上跳出一句心情小語
  - 放煙火：馬上放一次下班煙火，可以先看看效果
  - 設定…：開啟設定畫面
  - 重設位置：讓時鐘回到螢幕右上角
  - 結束：關閉時鐘

時鐘不會出現在工作列上，要關閉請用右鍵選單的「結束」。重複開啟也只會出現一個時鐘。

## 設定畫面

在時鐘上按右鍵 →「設定…」。改完按「儲存」就會立即生效，不用重開時鐘。

**一般**
- 上班時間、下班時間、午休開始、午休結束（上班時間用來計算進度條）
- 下班時放煙火：取消勾選就不放煙火；旁邊的「測試煙火」可以馬上放一次看看
- 開機自動執行：勾選後每次登入 Windows 會自動開啟時鐘

**心情小語**
- 顯示心情小語：取消勾選就不會自動跳出
- 換句頻率：每 10、15、30 或 60 分鐘跳一句
- 選擇「早上／中午／下午」，可以新增、修改、刪除該時段的小語：
  - **新增**：在清單下方的輸入框打字，按「新增」
  - **修改**：點選清單中的一句，內容會出現在輸入框，改好後按「修改選取」
  - **刪除**：點選要刪除的小語（按住 Ctrl 可以多選），按「刪除選取」
  - **還原這個時段的預設**：恢復成內建的 100 句

**播放統計**
- 每一句小語播放過幾次，點欄位標題可以排序
- 「清除統計」會把所有次數歸零

## 心情小語什麼時候出現？

- 只在**平日、下班前**自動出現，下班後和週末不會跳
- 依照目前時間，從對應時段的小語裡隨機挑一句：
  - **早上**：午休開始前
  - **中午**：午休時間
  - **下午**：午休結束到下班
- 每個時段的小語都輪過一次才會重複
- 時鐘開啟約 5 秒後跳第一句，之後依照換句頻率跳，進入或結束午休時也會馬上換一句
- 泡泡會停留 15 秒後消失，點一下泡泡可以提早關掉

## 預覽下班倒數

只想看煙火的話，在時鐘上按右鍵 →「放煙火」就可以了。

想連最後 10 秒倒數一起預覽：在資料夾空白處按住 Shift + 右鍵 →「在這裡開啟 PowerShell 視窗」，輸入：

```powershell
.\OffWorkClock.exe --demo
```

會另外開一個時鐘，時間設在下班前 15 秒，接著就會看到最後 10 秒倒數和煙火。預覽不會修改設定，也不會計入播放統計。看完在它上面按右鍵 →「結束」即可。

## 常見問題

**雙擊 exe 沒反應**
可能時鐘已經在執行，只是被拖到看不到的地方。在工作管理員結束 `OffWorkClock` 後再重新開啟，再用右鍵選單的「重設位置」讓它回到右上角。也可能是被防毒軟體擋下了，請參考安裝步驟下方的說明。

**雙螢幕可以用嗎？**
可以。時鐘可以拖到任何一個螢幕，泡泡和設定畫面會跟著出現在同一個螢幕，下班煙火會在所有螢幕一起放。如果拔掉外接螢幕，時鐘下次開啟時會自動回到主螢幕右上角。

**搬動了資料夾之後就不會自動啟動了**
開機設定記住的是舊的位置。在新的位置開啟時鐘，按右鍵 →「設定…」→「儲存」一次就會更新。

**按儲存時出現「無法寫入設定檔」**
程式所在的資料夾沒有寫入權限，例如放在 `C:\Program Files` 底下。請把資料夾搬到 `C:\OffWorkClock` 這類一般位置。

## 給開發者

原始碼需要 Python 3 才能執行或打包：

| 檔案 | 內容 |
|---|---|
| `clock.py` | 時鐘本體（主程式） |
| `appconfig.py` | 設定檔讀寫 |
| `quotes.py` / `default_quotes.py` | 心情小語輪播、播放統計 / 內建的 300 句 |
| `bubble.py` | 對話泡泡 |
| `settings.py` | 設定畫面 |
| `autostart.py` | 開機自動執行（寫入目前使用者的 Run 登錄機碼） |
| `fireworks.py` | 下班煙火 |
| `monitors.py` | 多螢幕範圍查詢 |

資料檔都放在程式旁邊：`config.json`（設定）、`quotes.json`（修改過的小語，沒有就用內建的）、`stats.json`（播放統計）。

```powershell
python clock.py --demo                     # 預覽倒數和煙火
python -m pip install pyinstaller          # 只需要裝一次
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

打包好的資料夾會在 `dist\OffWorkClock\`，裡面有 exe、設定檔和這份說明，`config.json` 的位置會重設成右上角。直接複製這個資料夾到其他電腦就能用。
